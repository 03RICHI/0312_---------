# ①課題名
読書メモアプリ

## ②課題内容（どんな作品か）
- 読んだ本のタイトルとメモ・感想を記録できる、ブラウザで使う読書メモアプリ
- 入力したメモは localStorage に保存されるため、ページを閉じたり再読み込みしたりしても消えない
- 保存したメモは新しい順に一覧表示され、件数・登録日も表示する
- メモの1件削除と、すべて削除ができる
- HTML / CSS / JavaScript のみで作成（ライブラリ不使用）

## ⑤工夫した点・こだわった点
- **データの保存方法**：メモを「id・タイトル・メモ・日付」をまとめたオブジェクトの配列で管理し、`JSON.stringify` で文字列にして localStorage に保存、読み込み時は `JSON.parse` で配列に戻すようにした
- **初回起動への対応**：まだ何も保存されていないときは空の配列を返すようにし、初めて開いたときもエラーにならないようにした
- **削除の仕組み**：各メモに `Date.now()` で一意の id を付け、削除ボタンを押したメモだけを `filter` で取り除けるようにした
- **入力チェック**：タイトルが空のまま保存しようとするとエラーメッセージを表示。入力を始めるとメッセージが消えるようにした
- **誤操作の防止**：「すべて削除」は確認ダイアログを出してから実行するようにした
- **安全な表示**：メモの表示には `innerHTML` ではなく `textContent` を使い、入力した文字がHTMLとして解釈されないようにした
- **見やすさ**：新しいメモを一番上に表示し、メモがないときは案内文を表示。メモ内の改行もそのまま表示されるようにした
- **デザイン**：白いカードと落ち着いた背景色のシンプルな見た目にし、スマホ幅でも使いやすいレイアウトにした

## ⑥難しかった点・次回トライしたいこと（又は機能）
### 難しかった点
- **localStorage は文字列しか保存できない**：配列をそのまま保存すると正しく読み込めないため、JSON形式に変換して保存・復元する必要があった
- **保存と表示のタイミング**：追加・削除のたびに「配列を更新 → localStorage に保存 → 一覧を再表示」の順番で処理し、画面と保存データがずれないように組み立てた

### 次回トライしたいこと
- 保存したメモの編集機能を追加したい
- タイトルやメモの内容で検索・並び替えができるようにしたい
- 評価（★）や読了日、ジャンルなどの項目を追加したい
